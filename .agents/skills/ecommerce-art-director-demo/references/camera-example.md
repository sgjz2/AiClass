# 相机 Demo：实际试跑示例

输入：用户提供的黑色 Sony 相机透明图；缺少确切型号、性能和促销资料。设计假设为城市日常摄影消费者，4:5 活动概念海报。

画面关系：巨大的取景边框把日常街景组织为画面；前景相机连接摄影主题。暖冷对比为艺术隐喻，不代表该相机的实测成像效果。文案为“日常 / 值得入镜”“换个视角，发现身边的故事。”。

制作：以商品图作为身份参考，统一生成相机与场景；保留原图作核对，不宣称像素一致。第一版框与街景抢眼，因此第二次实际图像编辑要求减薄框、降低背景高光、保留相机结构和质感。最后以独立文字层排版，按钮按实际字形居中。

局限：只提供商品身份参考，没有独立的商业广告品质图；已有前版仅作为设计基线，未做同工具同输入的盲评。小铭文存在生成差异，不能直接用于正式商品投放。样张验证流程可以运行，不证明跨品类质量提高。

实际反馈：用户认为精修版油腻、AI 味重。方向随后改为柔和日光、干燥材质、普通街区，取消实体边框，减轻标题与按钮的表现强度。旧版保留作失败案例，不能把旧版描述为已获认可的优秀参考。新的自然版本仍待用户评价。

第二次反馈：自然版缺少视觉冲击，也没有明确核心价值。用户随后提供“高像素拍摄能力”作为卖点，新的版本围绕整体照片与局部纹理建立放大关系，标题直接说明主信息，CTA 引导查看商品参数。图像标明创意示意，未冒充相机实拍；像素数字和型号没有添加。这次修正体现先确定购买理由、再选择视觉张力的流程，效果仍未做独立验证。

项目中对应目录：`tests/art-director-demo/`。打包演示中的对应目录为 `case/`，包含原商品参考、任务摘要、完整指令、前后画面、排版配置和检查记录。重生成需要可用图像工具；现有画面可以用 Python/Pillow 重新排版。字体路径需按本机修改。
