# 电商视觉开发与精修

Agent制作实际海报并检查，用户评价；相机或鞋案例不是默认版式。按用户的版位、数量、语言和方法执行。

当前用户偏好：非必要不加底部全宽文字带，优先背景铺满画面、文字落在背景安静处；真正的可读性/传播需求可以例外，小CTA不等于整条底栏。人物主次是参考理解要求：非必要不出现完整人物，优先与用途相关的局部手部或动作，商品为主体；不能把近景人脸参考套成大脸肖像，让面部、眼神或人物面积抢走商品注意。明确人物主导的任务另行判断。

当前商品主导偏好：商品主体占比明显大于完整主标题字组，商品保持第一视觉主体；尺寸安排与复查按[标题与装饰统一规则](references/typography-and-ornament.md)执行。

从商品与资料确定 `受众/情境/核心利益与证据/必用文案/身份约束`。未知性能、参数、价格、活动不补造；参考中的认证、优惠或样张不移植到商品。

商品可换摆放、构图和机位，但不能补出原图未展示且未确认的结构。区分可见、已确认和未知部分；未知部分保持遮挡或换不暴露它的视角，必要时补充商品视图或保留真实商品层。不能因为通常存在或场景需要就添加花柄、接口、底座、支撑件、配件；仅有花头的原图不能为插花瓶而补造柄部。布景不能连成新商品结构或冒充随附物。

人物局部裁切先检查机位、观察者/操作者/商品位置、手臂来源和动作目标。不能保留迎面持机视角，再简单擦掉操作者头部或身体；应保留必要局部并控制主次，或重新设计机位/商品构图。这是空间与动作逻辑要求，不是全局禁止人物或手部。

用户给参考或反馈时，读 [实际参考图谱](references/local-reference-atlas.md)，按 [图像索引](references/local-reference-index.json) 实际打开相关图片。写明可迁移机制、对应制作指令和不能照搬内容；按索引 `polarity` 选图：用户指定`不应该的图片`和`像电商首页的图片-文字量大元素多`两个目录现有图均为负面，其余为正面。负面仅用于诊断对照，不作为正向品质/风格输入；移动文件时先同步标签与路径。负例分别关注拥挤、主体缩小、贴纸感、无作用特效和叙事杂乱，不把减装饰当唯一修法。

先选择完整促销、材质、动作、概念空间或图形关系，再决定工具。文字品质反馈先读 [实际文字研究](references/typography-reference-study.md) 并打开适用T1/A1原图，明确主题、准确文案及关键构图关系，字形、强调、排法与装饰保留自主发展空间；保留好背景局部改字，不能只写“高级艺术字”，不默认三枚等大圆形卖点。读 [文字与装饰生成](references/generative-typography.md)：标题、价格字形、图标、按钮和装饰可以整图生成或独立生成，不强制先无字背景再全部系统字体。大字和概念悬浮可以成立，商品识别和事实必须可靠。按需参考 [制作判断](references/production.md)。

方向未定时比较少量机制不同的小样；已有选定画面时保留基线做具体局部修改。所有输入标明身份/构图/光影/字形角色；主指令含准确文案。整图生成核对商品细节，原商品层合成核对光影与空间，不能以像素不变抵消融合差。

文字正确而字形有效时保留；错字/数字先局部图像编辑，必要时用 [精确排版工具](references/layout-contract.md) 修正，匹配原字重、纹理、底纹和透视。脚本是可选工具，不是设计默认流程；不要把好艺术字替换成平淡黑字和矩形卡片。

打开实际原尺寸与投放/手机尺寸导出，检查身份、全部必用事实、主题、商品焦点、文字装饰关系、交易信息归组、材质与支撑/动作关系。概念悬浮检查空间一致，拟真路线检查接触阴影。每次记录 `具体问题 → 实际修改 → 必须保留项 → 导出 → 复查`。相机创意例按需见 [案例](references/camera-example.md)，生成摄影效果不得充当真实样张。

标题、装饰、商品与空间共同发展。按[统一判断](references/typography-and-ornament.md)检查商品主导、自然阅读与整体协调；整行对比和局部强调都可成立，氛围与美感可独立成立。把审美要求写成结果目标，不预设固定字体、行组轻重或线型，也不在转译工具指令时另加保守样式限制；商品结构与必用信息仍须准确。

遇“平淡”增强有依据的关系/字形/构图张力，遇“油腻”定位无作用光效/材质/装饰；不在极简与特效之间盲目摆动。没有用户测试不写盲评，没有实测不宣称转化提升。事实或商品身份仍错不能宣布正式通过；不能无限重生成。

交付成品、实际尺寸、输入与生成编辑指令、可重做配置（若合成）、修改前后和复查证据。整图生成不伪造分层源文件。保留未解决项，内容正确与视觉完成度分别评价。
