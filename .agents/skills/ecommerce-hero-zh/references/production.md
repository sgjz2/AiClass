# 制作与验收

用途：管理明确约束、简报、商品依据、制作路径、局部修正和交付检查。制作或精修时读取；审美构思分别使用相应设计文档。

## 明确要求与禁止项

在简报中区分用户明确要求、明确禁止项与默认偏好，并记录各自适用范围。明确要求与禁止项是验收硬约束，不因审美自由、参考形式或文档精简而降级。改变这些约束需要用户明确更新；“可以更好看”不构成变更依据。

先读取当前用户要求及任务包中的简报、品牌规范和约束记录。某个商品或案例的特殊禁令保存在该任务资料中，执行时带入实际指令并检查；通用规则负责保护这些要求，不将它们扩展到其他商品。

## 简报与商品依据

提取传播目标、版位、受众、商品核心价值与依据、品牌语气、必用文案及交易条件、语言、数量、尺寸和格式。把确认的商品事实转为与受众有关的购买理由，再确定本次主信息及其视觉表达。价格、活动信息、双语版本和具体素材类型是否需要，由任务决定；示例不构成材料门槛或输出模板。区分用户要求、资料事实、设计推断与未知信息。只有缺失会改变商品身份、必用信息或核心方向时集中询问，其余作合理选择并继续。

记录原商品的轮廓、色彩、图案、连接结构、Logo/铭文、数量和配件。摆放与视角可以调整，但不得补造原图未展示且资料或用户未确认的结构、部件或随附物；同类商品的常见配置和场景需要不是确认依据。未知区域可保持遮挡、换视角、补充资料或采用可靠的真实素材。

布景道具不得与商品连成未确认的新结构、冒充随附物，或绕过用户禁止的展示方式。标注“场景道具”“不包含”不能豁免这些约束；检查商品与道具的实际连接、支撑和遮挡所暗示的结构。

价格、日期、认证、销量、性能、赠品与配件以确认资料为准，不补造未知事实。Logo 优先采用原资产，缺少时可用提供的品牌文字，不用新生成的标志冒充原标志。展示实测效果使用可追溯素材；生成的效果画面标明创意示意。若要求现行平台合规，核对对应官方规则。

商品图提供身份依据，成品广告提供设计参考。遵从用户对参考观看和工具输入的限制；可用图库的选择方法见[参考使用](reference-guide.md)。

## 选择制作路径

商品结构、包装图案、标志与必用文案准确，是所有制作方法的共同验收要求。“严格保留”不自动意味着冻结整件商品的原像素、机位和光照，也不能直接推导出必须使用真实商品层。先设计商品、空间、光影与文字的整体关系，再依据现有素材、工具能力、指定资产要求和实际误差选择或组合方法：

| 方法 | 能解决的问题 | 采用与组合时检查 |
|---|---|---|
| 原素材图像编辑与局部生成 | 保留有效商品或画面，发展场景、光照和局部内容 | 编辑范围、身份细节与新旧区域融合 |
| 参考引导的整图生成 | 商品、空间、光影、文字和装饰共同构图 | 原素材作为身份依据，核对商品细节、全文及整体关系 |
| 真实资产与生成资产合成 | 使用指定资产，或通过资产修正获得更可靠的局部结果 | 资产适用范围、机位、光照、边缘、反射及支撑融合 |
| 文字/装饰独立生成与精确修正 | 发展局部表达、修复生成错误或提供可编辑内容 | 风格、纹理、透视、叠压与可读性 |

同一画面可以组合多种方法。将需要准确的区域分别处理，局部标志或纹样问题不自动要求替换整个商品。用户或品牌规范明确指定原像素保留时，记录对应资产和范围，在该范围使用真实资产；不能把一般身份准确要求自行升级为逐像素保留。生成结果仍须按原素材核对，不承诺未经验证的精确一致。

优先考虑让标题、价格字形、图标、按钮和装饰参与图像生成，保留正确且有效的生成文字。选定方法须同时满足商品准确、营销表达与画面融合；不因技术保真而忽略贴图感。

使用真实图像工具制作或编辑，脚本负责合成与精确排版。精确工具仅在需要时读取[工具约定](layout-contract.md)。

## 编写实际制作指令

指令包含确认事实与准确文案、适用的明确要求与禁止项、本次主题及关键构图关系、可自主发展的审美选择。将有关的结构与展示禁止项写进实际工具指令，不以“商品保真”或“遵守 skill”概括代替。输入图注明身份、构图、光影或文字角色，并记录实际传入的素材。

将用户选择和本次必要决定落实到指令，其余字形、装饰和材料表现由模型协调。全文生成路线明确包含图内文字；纯背景路线按用途留出后续合成区域。

## 局部修正

保存选定基线。每轮简短记录具体问题、实际修改和保留项，再检查新导出。

场景和商品有效时，文字问题优先局部编辑；持续错字可用风格匹配的精确修正。身份错误先定位范围，再选择局部编辑、真实资产修正或调整生成方法，并检查修正后的光影融合；不自动把整个主体盖回原素材。只有整体构思失效或局部编辑持续无效时，才重构画面；持续失败则保留可用成果并报告具体缺口。

## 验收与交付

打开实际原尺寸与接近投放/手机尺寸的导出，分别核对：

| 检查 | 通过依据 |
|---|---|
| 明确要求 | 简报中适用的要求与禁止项逐项满足；道具说明没有掩盖被禁止的结构或展示方式 |
| 身份与事实 | 结构、图案、标志、配件符合资料；必用文案、数字、币种、日期与条件逐项准确 |
| 营销表达 | 能辨认商品，读出本次主信息及与受众有关的价值或品牌语气；任务要求的行动信息清楚 |
| 构图与阅读 | 商品主导；标题具有本次主题语气、阅读节奏和图文关系，装饰按整体协调判断；辅助信息和行动信息按任务形成层级 |
| 材质与空间 | 光影、反射、透视、遮挡与支撑/动作关系成立，细节强度适合观看尺度 |
| 实际规格 | 文件存在且可读；尺寸、裁切、格式、语言和数量满足任务 |

明确要求、禁止项、身份或必用事实仍有错误时，继续修正；未能修复的成果标为概念或未完成，并列出待修项，不以审美得分抵消硬约束失败。审美评价依据实际画面，自查与用户验收分开记录。

传播表达以成片可见关系判断；没有消费者测试或投放数据时，不把设计自查等同于点击率、购买意愿或转化提升的证明。

交付成片及简短说明，保留原输出、输入素材、实际指令与编辑链。合成路线另附配置或源文件，整图生成保留复做材料即可。规格与完成情况只报告实际核查结果。
