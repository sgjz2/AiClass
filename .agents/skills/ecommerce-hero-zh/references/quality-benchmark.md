# 用户确认的视觉质量基准

## 适用范围

用户于 2026-10-13 明确要求：后续使用本技能，成片至少以提供的 12 张海报所体现的设计完成度为目标。L1-01～L1-05、P1-01～P1-07 是用户认可的正面品质参考，不再仅作可选局部案例。此要求适用于本技能制作的电商主视觉；用户对当前项目的新要求优先。

对标的是视觉判断和完成度：商品是否有吸引力、光是否塑造真实材料、空间是否有深度、文字是否组织阅读。题材、颜色、人物、巨字、台座和具体构图按项目选择。无需把所有作品改成黑底、红底或鱼眼，也不能靠添加参考中的元素数量宣称达标。

## 制作前先建立可见目标

除用户明确禁止观看参考外，新海报或整体重构时，先从这 12 张中选 1～3 张与任务匹配的原图实际打开；通常一张负责主构图，另一张补充光影或文字。小范围精修沿用已看过的相关参考，无需每轮重复加载。原图随技能保存，按 [参考使用](reference-guide.md) 解析路径；仅读分析文档不能算看过原图。

将选择写成简短工作记录：`参考 ID → 最值得迁移的关系 → 本次商品如何实现 → 在成片何处检查`。说明商品的主要展示面、机位、明暗焦点及文字如何与商品相互呼应，然后进入制作。方向开放时，先比较两种构思关系，选一种发展；不必为比较额外生成多张或让用户选。

选择路径：

- 数码发布、材料质感：L1-03 / L1-04 / L1-05；需要悬念的预热再考虑 L1-01。
- 屏幕或发光表面：L1-02，重点看亮源与反射的连续关系。
- 手持、操作或生活方式：P1-01 / P1-02 / P1-04 / P1-05。
- 参数参与构图、户外使用：P1-06。
- 服务场景或动作概念：P1-03 / P1-07，根据实际任务确定人物与商品主次。

具体逐图解读见 [光影与透视研究](lighting-and-perspective-study.md)。

## 这批参考共同建立的标准

| 判断维度 | 达到目标的可见表现 | 需要退回修改的表现 |
|---|---|---|
| 核心视觉关系 | 能说出并在图里看到一个主导关系，如商品压住背景字、前景商品与动作连成对角线、同色主体靠材料和亮度分层 | 只剩“好看的房间＋产品＋几行字”，更换成无关商品仍不影响构图 |
| 商品表现力 | 展示面、尺度与拍摄角度共同突出轮廓、材料或用法；商品有明确视觉权重 | 商品仅因文件放得大而算主角，视觉注意力实际被脸、家具、标题或装饰抢走 |
| 光影与材料 | 亮区解释曲面与转折；织物、塑料、玻璃和金属有各自响应；暗部保留需要识别的结构 | 均匀描边、全图泛白、塑料金属化、平贴商品、与环境无关的投影 |
| 空间与动作 | 支撑、遮挡、透视或概念动作能读通，近中远景有明确关系 | 只有背景虚化而没有空间设计，手臂无来源、产品接触失真或机械变形 |
| 文字与信息 | 第一眼读主信息，第二眼读支持信息；字组比例和间距配合产品轮廓、运动方向或留白 | 标题、品牌、参数、价格等强争抢；均匀排满；靠成排图标和按钮填空 |
| 色彩与完成度 | 主色统一但亮度和材料有层次，局部对比集中；边缘、标识和文字经得起原尺寸检查 | 靠滤镜统一颜色、无来源光晕、碎细节过多，缩略图热闹而原图粗糙 |

不同任务可以用不同方式达到这些表现；不使用固定面积比例、打分总和或“高级感”口号替代视觉判断。参考本身的低分辨率、密集小字或预热暗部不作为需要复制的缺陷。

## 把方法写进实际制作指令

避免仅写“旗舰、震撼、商业级、参考某品牌”。指令至少讲清本次选中的关键关系，并让其余设计自由发展：

- 光影路径示例：深色安静空间中，宽面柔光沿真实外壳转折形成亮暗层次，较窄的边缘反射分离轮廓；接触区投影建立重量，品牌区清楚；背景字退到产品后方。材料以真实商品为准。
- 透视路径示例：相机靠近前景商品，保留准确展示面；人物和场景后退，手腕连接与操作方向完整；标题沿动作留下的负空间组织，不挡产品标识。
- 同色路径示例：主体与背景共用一个主色系，通过暗背景、受光面与不同粗糙度分开；辅助视图为主视图让位，已确认的价格或规格形成独立次层。

画幅改变时重建关系：竖图的上下堆叠在横图中可转换为斜向或中央聚焦，不能只挤压参考，也不默认转换成左右各半。商品图负责身份；风格参考负责设计关系。传入图像工具时标明角色，禁止复制参考品牌、参数、人物身份或把参考商品混进当前商品。

## 交付前的对照与返修

把实际导出与选定参考置于近似观看尺寸，对照上述维度。缩略图检查焦点与阅读顺序，原尺寸检查材料、边缘、结构与文字。记录最明显的差距、对应修改与复核结果；参考图像未打开、导出未检查时，不写“达到参考水平”。

身份、文案、价格、规格检查通过后，还须完成视觉检查。若主导构思或光影/空间明显弱于选定参考，应继续针对性修改。整体关系失败就重构，局部问题只修局部；连续两次针对同一问题仍无改善时，重新判断制作路径，保留最佳版本并如实说明尚未解决的差距，不无限微调或把未达标稿包装成完成稿。自查不能代表用户验收，也不能保证生成工具每次达到同样水平。

## 本次失败的具体教训

2026-10-13 的 NIVORA 初稿被用户否定：暖白家居、左侧大标题与四行卖点、右侧产品、左下价格按钮形成常见模板，缺少一个足以记住商品的主导关系；自查只核对了文字和尺寸，没有执行参考品质对照。

以后遇到类似商品，先依据商品轮廓、功能或材质建立画面，例如让圆形主机与后方基站形成有主次的体块，以有方向的光塑造外壳，并让标题响应这组体块的留白。这个例子用于纠正本次失误，不把暖色、家居、衬线字或左文右图永久列为禁用。避免机械复用原有文案、固定分栏和卖点数量。
