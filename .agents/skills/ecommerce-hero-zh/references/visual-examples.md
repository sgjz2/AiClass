## 文字与装饰

| 参考 | 提取的形式 | 可借鉴的关系 |
|---|---|---|
| T1-01 | 超大青柠、紧凑中英小字、衬线气质的 0 与小解释并排。 | 大图像与小字通过比例、间距和留白形成张力。 |
| T1-02 | 横题转入竖向字序，单字旋转；黄色弹跳弧与球场斜线参与构图。 | 转向、旋转与开放端点共同建立阅读节奏。 |
| T1-03 | 蓝字大小错落、错位紧叠，回环与瓶组共享空间。 | 字组与线条同向发展活力，大小和叠压形成层次。 |
| T1-04 | 黑色文字较平静，宽黄色曲线穿行于瓶组后方，与瓶组共享前后空间；顶部利益与底部优惠分工。 | 线重不必等于字重；差异可以通过层次和色彩组织而协调。宽曲线与底部促销区均按本次构思选择，不固定为模板。 |
| T1-05 | 轻薄大英文、细线图标与大括号采用白色；手掌和罐体占据中央，底部品名字组形成另一阅读区域。 | 大字的面积与视觉重量不同；字形、标点和图标可共享轻线语气。借形式关系，不将小罐体占比作为商品主导任务的默认。 |
| T1-06 | 巨大白色细长数字被深色斜瓶遮挡，细回环、涂鸦和侧边小字沿空间组织。 | 大数字可借轻笔画、退后层次与遮挡让商品仍清楚。百分比等内容必须有本次资料支持；不机械搬底带、宣称或斜瓶角度。 |
| A1-01 | 标题、价格与 CTA 延续斜向切角和红黑；鞋上红细节与文字颜色相连；底部将卖点与交易分组。 | 共同方向、笔端和强调色可连接多个信息组。底部信息区可借鉴其分工；强标题和强价格需按任务安排阅读顺序，价格、日期以本次资料为准。 |
| A1-02 | 深绿衬线气质标题、轻品名、同气质价格与白色杯体组合。 | 标题和数字气质协调，轻品名形成辅助层。 |
| A1-03 | 宽大黑色机身在标题下方占据主要区域；粗黑主行与较轻辅行构成完整标题，小卖点在下部。 | 整行轻重与商品尺度共同建立层级；不能只测标题单字。借重量关系，不规定所有题材上粗下细，不复制参数或新品宣称。 |
| A1-04 | 普通黑字、紧凑双行组合与大鞋体紧接排列。 | 普通字形也可通过间距、比例与商品邻接获得张力。 |
| A1-05 | 轻细上行、厚重下行由大括号围合，局部细弧、端点和附件细框同为酒红色；浅色细长主体低于标题。 | 不同线型可分担围合和局部节奏。正面标签不是各项自动通过：本图完整深色标题的重量仍值得与浅色主体单独比较，不能把大括号标题照搬成商品主导模板。 |
| A1-06 | 红色“浪漫”与红花呼应，小“把”和不同尺度词组仍保持句意；细红曲线流过留白；价格较小。 | 按语义强调和同行大小变化可成立，不能一律要求整行同粗。色彩、词组节奏和空间关系共同统一语气；不据生成图确认商品结构或报价。 |

|---|---|---|

| G7-05 | 方形风扇、三角支架与柔软起伏地形对照，表面明暗过渡柔和。 | 形体转折和几何/柔软材料对照建立空间。 |

| G7-07 | 音箱上部光泽与下部较暗网布有差异，蓝色边缘光和底座弧面分层。 | 按材料选择亮部，让光泽与纹理承担不同角色。 |
| G7-08 | 相机、冷蓝背景曲线与投影方向呼应。 | 产品姿态、背景形态和投影可共同建立概念空间。 |
| G5-03 | 银色缎带、瓶罐与紫色光场形成统一材质关系，促销短条退为次层。 | 反射与光场连接多个元素，文字按阅读角色分层。 |

| G6-02 | 手持洗发水提供尺度，大字退为背景并被商品遮挡。 | 手部建立尺度，商品与文字通过叠压共享空间。 |

| G6-04 | 拉伸动作、前景手部与线缆解释操作，黄色文字和引导线对应动作。 | 构图方向与动作方向一致，局部引线帮助理解。 |

| G6-08 | 嘴部、持麦手与麦克风构成收音情境，毛绒和机身材料不同。 | 人物局部与操作目标相连，材料对照突出商品。 |
| G7-01 | 手持牵引装置、狗和草地构成操作情境，商品在前景最大。 | 前景商品、使用对象与环境形成连续动作关系。 |

## 视觉分量诊断

| 案例与角色 | 实际关系 | 诊断边界 |
|---|---|---|
| G1-01，家电，负面 | 顶部品牌/热销、左侧排名/容量/利益/优惠与底部大价格均有高对比强调，商品虽然很大仍受到多个组竞争。 | 否定的是多个强焦点同时争抢，不是信息多或红色本身。负面图仅作诊断，不传作向往风格；保留必用条件，调整组级强调。 |
| 用户秋日 NORI 图，本轮诊断 | 杯体高大但浅色；深绿厚宋体标题、品名和卖点密集；橙色弧线/飘叶、圆徽章与笔刷价格底并存，价格本身也有强重量。 | 商品大不等于视觉主导；应在标题、价格与杯体之间明确主次。不同装饰并非逐项错误，问题是共同关系与分工是否清楚。保留有效秋日气氛，按竞争来源局部调整；不把整图重新分类为图库负面，不以它核实性能宣称。 |
