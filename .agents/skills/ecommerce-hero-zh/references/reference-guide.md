# 参考使用

用途：选择参考，并将实际观察转为制作决定。新作与整体重构按[质量基准](quality-benchmark.md)观看少量相关原图；精修沿用已选参考。用户明确禁止观看参考时直接依据简报和设计规则工作。

从图片提取的具体元素和组合关系见[形式参考](visual-form-reference.md)。本文件负责参考的选择与使用，形式文档负责可借鉴的设计例子。

## 图库入口与角色

[local-reference-index.json](local-reference-index.json) 保存图像 ID、路径、尺寸、观察机制、角色与哈希。12 张品质基准图保存在 `references/images/2026-10-07补充/`；其 `path` 和 `relative_path` 均相对于技能根目录（包含 SKILL.md 的目录）解析，`path_base: skill_root`，移动或安装技能无需改路径。其他历史条目仍可能使用外部绝对路径，使用前检查存在性。优先选择包内原图；缺失时记录未完成原图对照，不把旧路径存在于索引等同于图片可用。

按照 `polarity` 选图：`positive` 用于设计关系和品质参考；`negative` 用于定位问题和比较修法。现有负面标签来自“不应该的图片”和“像电商首页的图片-文字量大元素多”目录的用户分类，目录名和历史 ID 前缀不代表图像角色。移动或新增图片时重新确认角色并同步路径。

负面图只用于诊断对照，不作为向往的品质基准或生成风格输入。可保留其中成立的局部，但这不改变用户对整张图的负面分类。

参考提供构图、光影、字形或信息组织的关系，商品与营销事实由[制作依据](production.md#简报与商品依据)确定。查看与传入图像工具是两个动作，分别记录实际使用方式。用户要求不看参考时，直接依据简报和设计规则工作。

## 按问题选择少量参考

| 需要判断的关系 | 可从这些 ID 选择 | 观察重点 |
|---|---|---|
| 文字和装饰 | T1-01 至 T1-06、A1-01 至 A1-06 | 字组比例、语义强调、阅读转向、叠压、标点和留白节奏 |
| 光影与材料 | G7-04 至 G7-08、G5-03 | 亮区分布、形体过渡、表面响应、安静区域与空间一致性 |
| 创意环境与用途 | G4-01 至 G4-04 | 商品与场景、形态或概念的共同关系 |
| 人与商品 | G6 组、G7-01 | 机位、动作、尺度、裁切上下文与主次 |
| 信息和交易 | G2 组、G5 组、G3-04/07 | 任务类型、商品与辅助信息的分组和阅读顺序 |
| 暗场、同色与屏幕反射 | L1-01 至 L1-05 | 轮廓可读性、材料分区、接触光与前后层次；详见[逐图分析](lighting-and-perspective-study.md#光影与材料) |
| 前景透视、框景与动作 | P1-01 至 P1-07 | 镜头位置、近远尺度、手部连接与场景类型；详见[逐图分析](lighting-and-perspective-study.md#透视人物与动作) |
| 负面对照 | 索引中 `negative` 项 | 识别需要修正的关系，保留仍然成立的局部 |

这些 ID 是检索起点。实际按任务、画幅、信息量与标签选择，可在 JSON 中查找 `id`、`group`、`observed_mechanism` 和 `typography_mechanisms`。

## 从观看到制作

实际打开相关图像，提取与本次任务有关的关系，然后决定如何转译。可简短记录：`参考 ID/角色 → 可见关系 → 本次适用方式 → 实际指令或编辑动作`。

例如，字组大小变化可以借其阅读节奏；强反射可以借其亮区主次；人物裁切可以借其机位与动作关系。具体字体、线型、配色和道具由本次构思重新选择，观察结果是可选机制。

只读过索引时，将其作为选图线索；打开原图后再作视觉判断。已有画面有效时，用参考帮助定位局部差距。

## 补充图入库与版本

先按 SHA-256 判断完全相同文件；相同文件可复用记录。文件名、商品或构图相似但哈希不同的图片，保留为独立文件版本，用 `related_reference_ids` 标注可能关联，不覆盖旧 ID 或旧分类；只有打开双方原图后才确认视觉重复。索引条目数不等于不同设计的数量。

新记录保留实际尺寸、来源文件、哈希、可见机制、适用任务与迁移边界。`polarity` 保持 positive/negative 兼容。`reference_scope: user_quality_benchmark` 表示用户认可的品质基准，按任务选择相应维度对标；`mechanism_only` 仍表示仅可借鉴局部。`classification_basis` 和 `quality_confirmed_on` 记录用户评价依据，不能把已确认的这 12 张图再次降级为未经认可的局部案例。

新增可用图片不意味着旧图库已恢复。检索时优先选择存在且适合任务的原图；缺失路径可以保留历史记录，不得声称已观看。查看、作为生图输入与实际复用素材分别记录。来源标题不作为点击率、镜头型号或平台合规证据。
