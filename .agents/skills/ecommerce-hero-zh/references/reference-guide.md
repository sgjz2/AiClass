# 参考使用

用途：选择可用参考，并将观察转为制作决定。用户提供参考、允许调用图库或需要对照诊断时读取；常规制作可直接依据简报进行。

## 图库入口与角色

[local-reference-index.json](local-reference-index.json) 是可选本地图库的数据索引，保存图像 ID、目录、路径、尺寸、观察机制、正负标签与内容哈希。原图位于索引所指环境，源码包只提供索引；路径不可用时改用本次提供的素材或直接设计。

按照 `polarity` 选图：`positive` 用于设计关系和品质参考；`negative` 用于定位问题和比较修法。现有负面标签来自“不应该的图片”和“像电商首页的图片-文字量大元素多”目录的用户分类，目录名和历史 ID 前缀不代表图像角色。移动或新增图片时重新确认角色并同步路径。

参考提供构图、光影、字形或信息组织的关系，商品与营销事实由[制作依据](production.md#简报与商品依据)确定。查看与传入图像工具是两个动作，分别记录实际使用方式。用户要求不看参考时，直接依据简报和设计规则工作。

## 按问题选择少量参考

| 需要判断的关系 | 可从这些 ID 选择 | 观察重点 |
|---|---|---|
| 文字和装饰 | T1-01 至 T1-06、A1-01 至 A1-06 | 字组比例、语义强调、阅读转向、叠压、标点和留白节奏 |
| 光影与材料 | G7-04 至 G7-08、G5-03 | 亮区分布、形体过渡、表面响应、安静区域与空间一致性 |
| 创意环境与用途 | G4-01 至 G4-04 | 商品与场景、形态或概念的共同关系 |
| 人与商品 | G6 组、G7-01 | 机位、动作、尺度、裁切上下文与主次 |
| 信息和交易 | G2 组、G5 组、G3-04/07 | 任务类型、商品与辅助信息的分组和阅读顺序 |
| 负面对照 | 索引中 `negative` 项 | 识别需要修正的关系，保留仍然成立的局部 |

这些 ID 是检索起点。实际按任务、画幅、信息量与标签选择，可在 JSON 中查找 `id`、`group`、`observed_mechanism` 和 `typography_mechanisms`。

## 从观看到制作

实际打开相关图像，提取与本次任务有关的关系，然后决定如何转译。可简短记录：`参考 ID/角色 → 可见关系 → 本次适用方式 → 实际指令或编辑动作`。

例如，字组大小变化可以借其阅读节奏；强反射可以借其亮区主次；人物裁切可以借其机位与动作关系。具体字体、线型、配色和道具由本次构思重新选择，观察结果是可选机制。

只读过索引时，将其作为选图线索；打开原图后再作视觉判断。已有画面有效时，用参考帮助定位局部差距。
