# 图像提取的形式参考

用途：保留从参考图中提取的具体元素与组合关系，作为可选设计形式。发展文字、材质、构图或信息组时按需读取对应章节；这些已记录的形式也可用于不调用图库的构思。

每项分为可见形式和可借鉴关系，根据本次题材选择、改编或重组。整体主次与事实要求按设计及制作文档执行，商品结构和商业信息以本次资料为准。需要进一步视觉核对时，通过[参考使用](reference-guide.md)及[索引](local-reference-index.json)定位原图。

## 文字与装饰

| 参考 | 提取的形式 | 可借鉴的关系 |
|---|---|---|
| T1-01 | 超大青柠、紧凑中英小字、衬线气质的 0 与小解释并排。 | 大图像与小字通过比例、间距和留白形成张力。 |
| T1-02 | 横题转入竖向字序，单字旋转；黄色弹跳弧与球场斜线参与构图。 | 转向、旋转与开放端点共同建立阅读节奏。 |
| T1-03 | 蓝字大小错落、错位紧叠，回环与瓶组共享空间。 | 字组与线条同向发展活力，大小和叠压形成层次。 |
| T1-04 | 文字字重变化克制，黄色宽曲线形成背景动势，瓶体前后叠压。 | 平静文字、宽曲线与商品前后关系可以协调。 |
| T1-05 | 轻薄大英文、中文品名的大括号、手掌与罐体组成画面。 | 标点可围合文字，宽窄、字距与产品轮廓共同构图。 |
| T1-06 | 细长巨大 100%、斜向瓶体、回环箭头与轻线涂鸦共享前后空间。 | 大数字、轻笔画与有意叠压可形成轻重和方向的节奏。 |
| A1-01 | 黑红斜向切角字、错行和速度笔触贯穿鞋海报的标题与价格。 | 字形、笔触和信息组可以延续相同动势。 |
| A1-02 | 深绿衬线气质标题、轻品名、同气质价格与白色杯体组合。 | 标题和数字气质协调，轻品名形成辅助层。 |
| A1-03 | 粗黑“轻松创作”与轻细“精彩随行”组成标题组，大相机靠近文字。 | 整行重量对比与图文距离共同建立层级。 |
| A1-04 | 普通黑字、紧凑双行组合与大鞋体紧接排列。 | 普通字形也可通过间距、比例与商品邻接获得张力。 |
| A1-05 | 轻细“聪明控温”、厚重“温柔护发”；宽大括号、细弧、点和附件侧框并存。 | 不同线型分担围合、局部节奏和分组，形成完整字图关系。 |
| A1-06 | 小“把”、红色大“浪漫”、深绿大小词组；细红曲线承接留白并呼应花朵。 | 词组强调与同行大小变化形成语义节奏，曲线和商品色彩共同协调。 |

## 人物与动作

| 参考 | 提取的形式 | 可借鉴的关系 |
|---|---|---|

| G6-02 | 手持洗发水提供尺度，大字退为背景并被商品遮挡。 | 手部建立尺度，商品与文字通过叠压共享空间。 |
| G6-03 | 近景手持水瓶放大商品，人物退后，蓝色商品与天空呼应。 | 近远关系保持商品焦点，场景色彩连接产品。 |
| G6-04 | 拉伸动作、前景手部与线缆解释操作，黄色文字和引导线对应动作。 | 构图方向与动作方向一致，局部引线帮助理解。 |
| G6-05 | 人物伸手指向前景瓶体，紫色贯穿服饰和包装，后方小瓶提供层次。 | 动作、色彩和尺度把人物与产品组成一个视觉组。 |
| G6-06 | 手托耳机建立尺度，淡色大字退为背景，留白和颜色统一。 | 实物尺度、背景文字与安静空间共同形成简洁构图。 |
| G6-08 | 嘴部、持麦手与麦克风构成收音情境，毛绒和机身材料不同。 | 人物局部与操作目标相连，材料对照突出商品。 |
| G7-01 | 手持牵引装置、狗和草地构成操作情境，商品在前景最大。 | 前景商品、使用对象与环境形成连续动作关系。 |
