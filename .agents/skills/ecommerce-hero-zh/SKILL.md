# 电商商品营销主视觉设计

目标：让目标消费者在短时间内认出商品、理解最重要的购买理由，并看清必要的价格或活动信息，进而愿意点击或购买。依据具体任务决定交付图像、可编辑源文件、设计说明或方案；不要把课程案例的品牌、画幅和文案当作通用要求。

## 1. 整理任务与输入

先从用户资料中提取：商品及品牌、目标消费者、投放场景、传播目标、主要卖点、产品图片与 Logo、必须出现的文案、价格和活动规则、使用语言、尺寸与格式、品牌规范、交付时间。把信息分成“已确认”“需要确认”“可由设计者决定”。

若商品身份、强制文案、活动条件或画布规格缺失且会改变设计结果，提出少量明确问题；能合理继续的部分先推进。不要自行编造功效、参数、折扣、日期、价格、认证或品牌承诺。对不确定的事实，在方案中标记待确认，不放入最终营销文案。

## 2. 建立内容层级与视觉方向

用一句话概括目标受众最该记住的商品价值。确定一个主卖点，其余信息按重要程度排序：商品与品牌、主标题、关键卖点、价格和活动规则、行动提示等。根据投放位置和浏览速度决定取舍，保证手机缩略图中仍可辨认核心信息。

提出至少两个真正不同的视觉方向，并简述各自的构图、色彩、字体、商品呈现方式、信息层级和适用理由。选择方向时优先考虑传播目标、品牌一致性、资料质量和制作可行性；说明选择依据。若用户已有明确方向，直接沿该方向深化，无须机械地产生备选。

## 3. 制作主视觉

以商品为视觉中心，安排足够清楚的标题和信息区。控制文字量、对比度与留白，使商品轮廓、品牌标识、价格及限制条件不被装饰元素遮挡。保持品牌规范，避免改造 Logo 或把产品外观改得与原商品不符。

如果使用生成式图像，适合用于背景、氛围或辅助元素；重要商品外观、Logo 和法定/活动文案要根据可信原始素材核对。图像中的文字、数值和细节应在最终制作阶段逐项校正。保留素材来源、关键提示和人工修改记录，方便团队复查。

## 4. 检查与迭代

至少检查：

- **传播**：一眼能否看出商品是什么、卖点是什么、希望用户做什么？
- **事实**：参数、价格、时间、活动条件与用户资料是否一致？是否出现未经证实的承诺？
- **视觉**：层级、对齐、对比度、可读性、商品边缘和画面完整性是否合格？
- **品牌**：Logo、色彩、语气和商品外观是否符合给定规范？
- **交付**：尺寸、格式、语言版本及源文件是否符合任务要求？

在实际投放尺寸或接近手机浏览的大小下复查。记录发现的问题、修改动作和修改后的结果；若条件允许，让未参与制作的人在短时间浏览后复述其看到的核心信息，再针对误读进行修改。

## 5. 输出

交付任务要求的最终文件，并附简短说明：设计目标、所选方向及理由、已核对的事实、仍需确认的事项、素材来源和修改摘要。若无法生成实际图像，交付可执行的版式方案与制作指令，并明确说明当前只完成了方案阶段。
