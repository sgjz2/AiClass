# 电商商品营销主视觉设计

把商品资料转成一张能快速传达核心价值、引导点击或购买的静态主视觉。按具体任务交付设计方案、成品或改稿；不要把课程案例的品牌、价格、画幅、语言版本当成默认要求。执行者应让未参与沟通的同学仅凭本 Skill 和同一份输入也能复现主要设计决策。

## 1. 确定任务边界与输入

先识别用户要的是**策划、制作，还是评审已有画面**。记录目标受众、投放位置、传播目标、商品与品牌、商品实拍或包装图、Logo 和品牌规范、可证实的卖点、必用文案、价格与活动条件、语言、画布规格和交付格式。把每项标为“已确认”“待确认”或“设计选择”。

商品身份和传播目标是策划的最低输入；要制作忠于真实商品的成品，还需可信的商品图片或足以准确还原商品的素材。若缺失信息会改变主卖点、商品外观、强制文案或画布规格，集中询问关键问题。其余空缺可以在方案中写明假设并继续。价格、日期、折扣、功效、认证、销量、评价、平台规则等不得猜测；没有证据的内容不能进入最终画面。

若用户指定平台并要求符合该平台的现行规则，查该平台官方最新要求后再确定尺寸或内容限制；查不到就标明未核实，不能把案例规格或旧经验说成现行规则。

## 2. 从商品证据确定主信息

先写一份简短的任务摘要：`谁会看到 → 在哪里看到 → 需要立即理解什么 → 希望采取什么行动`。建立事实清单，将每个拟用卖点对应到用户资料、包装、说明书或其他可追溯依据；区分客观事实、表达方式和未经证实的设想。

从有依据的候选卖点中选**一个主购买理由**：优先考虑它是否与受众需求相关、是否能从画面中快速理解、是否有可靠证据、是否有利于区分商品。必要时保留少量辅助信息。不要把所有参数等权堆在一张图上。把技术参数转成用户收益时，原参数仍须准确，收益表述不能扩大事实。

形成内容顺序：商品和品牌 → 主标题或核心利益 → 必要证明或辅助卖点 → 价格/活动条件（如任务要求）→ 行动提示（如适用）。若信息在目标尺寸下拥挤，优先删减非必要文案，不靠缩小字号塞满画面；法定或活动限制条件不可因排版而隐藏。

## 3. 制定可执行的视觉方案

若用户没有指定方向，提出两个在**表达机制**上不同的方案，例如突出材质细节与突出使用场景，而不只是换两套配色。每个方案说明第一视觉落点、商品呈现、构图与留白、色彩和光影、文字区、品牌关系，以及它怎样支持主购买理由。根据传播目标、素材质量和品牌限制选一个，并记录取舍原因。用户已明确方向时直接深化。

在制作前写出一份简短的执行规格，至少包含：

| 项目 | 需要明确的内容 |
| --- | --- |
| 商品真实性 | 不能改变的轮廓、颜色、材质、包装文字、Logo 位置、结构和配件 |
| 画面结构 | 画幅、主体位置、大小、视角、阅读顺序、安全边距和留白 |
| 信息层级 | 主标题、辅助信息、价格与限制条件各放哪里；哪些内容不出现 |
| 视觉语言 | 配色、字体倾向、背景、道具、光影及其与品牌的关系 |
| 制作方式 | 使用哪些原始素材；哪些元素可生成；文字与数值如何后期校正 |

## 4. 制作并保留决策记录

让商品成为视觉中心，保证缩小到实际投放或手机浏览尺寸时，商品、主信息和关键价格仍可辨认。使用生成式工具时，可生成背景、氛围或辅助元素；对商品本体、Logo、包装文字和促销信息逐项对照原始资料。生成结果若改变商品结构或文字，不用美观理由接受错误，改用可信素材合成或人工修正。不要新增原商品不存在的功能、配件或规格。

记录最终使用的素材来源、主要生成指令或设计参数、人工修改，以及每条营销事实的依据。记录可以简短，但要足以让组员复查结果为什么这样设计。

## 5. 检查、修改、复查

先查**不能交付的错误**：商品外观或 Logo 与资料不符；价格、日期、折扣、规格、功效等缺少依据或写错；必需活动条件缺失；文字不可读或画面裁切；交付尺寸、格式、语言不符。发现任一项，先修正再交付。

再查传播质量：短暂观看后能否说出“是什么商品、为什么值得关注、下一步做什么”；第一视觉落点是否明确；主卖点是否比次要信息醒目；背景和装饰是否抢过商品；品牌语气是否一致。尽量请未参与设计的组员在接近实际显示尺寸下快速浏览并复述所见。把误读点、修改动作和复查结果记下来。不要凭主观印象宣称点击率或转化率会提升；没有实际数据时只评价可读性与传播清晰度。

## 6. 交付

按任务要求交付最终画面及需要的源文件，同时附一份精简说明：任务摘要、主购买理由及证据、所选方向、实际尺寸与格式、素材来源、检查和修改结果、仍待确认的事项。若只完成方案而尚未生成成品，应明确标注“设计方案”，并交付足够具体的执行规格，不把方案冒充最终作品。
