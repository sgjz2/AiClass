# 电商商品主视觉

用户提供商品、资料和评价；Agent 完成设计、真实图像生成/编辑、导出与复查，交付实际图像。用户明确选定语言、数量、方向或制作方法时遵从，不套案例的品牌、价格、画幅或双语数量。

当前用户偏好：非必要不使用底部贯穿全宽的文字带，优先让摄影/场景背景铺满画面，文案融入安静背景区域；小按钮不等于整条文字带。确有传播或可读性需求时可以例外，不能为模板方便默认加底栏。人物属于理解参考的主次要求：非必要不出现完整人物，优先用与用途有关的局部手部/动作；商品为主体，人物面积、清晰度、面部与眼神不能抢走商品焦点。参考里的近景脸部不意味着必须放大整张脸。另有明确人物主导的任务时再调整。

当前商品主导偏好：商品主体占比明显大于完整主标题字组，商品保持第一视觉主体；尺寸安排与复查按[标题与装饰统一规则](references/typography-and-ornament.md)执行。

## 先确定任务与事实

局部人物裁切须与机位和动作一起设计。检查观察者、商品、操作者的相对位置、手臂来源、视线或操作目标与支撑关系；不要保留迎面持机等依赖操作者在商品后方的视角，再直接抹掉其头部/身体。需要人物信息时可保留必要局部并压低主次；需要无人物时换合理机位或商品构图，不能留下悬空双手与失去操作者的动作。相机“删脸”失败是空间逻辑问题，不意味着局部手部或人物一律禁用。

确认本次是促销首屏、品牌KV、商品列表首图、使用场景还是详情模块。首页不等于统一的竖版促销模板。目标版位不明时按资料作合理设计选择；只有缺失会改变商品身份、必用信息或核心价值时集中询问，继续不依赖答案的素材检查。

从资料提取 `受众/情境 → 主关注理由 → 商品依据 → 画面线索 → 必用文案/交易条件`。区分明确事实、图片可见事实、设计推断和未知；参考图里的宣称和用户资料里的宣称分开。价格、日期、认证、销量、性能、赠品、配件等不得猜测。生成的场景、微观结构、清洁效果或摄影画面不是性能证据；实际效果展示优先可追溯素材，创意示意应明确标注。只在用户要求现行平台合规时查官方规则；参考图不证明合规。

检查原商品的轮廓、色彩、图案、结构、Logo/铭文、数量和配件。未允许形变时按严格一致核对。需要原图像素保留时采用可信商品层；不能承诺统一生成后像素不变。品牌Logo没有时使用资料中的品牌文字或说明缺失，不生成新Logo冒充原标志。

商品可以调整摆放、构图和机位，但不能因此补出原图未展示且资料或用户未确认的结构。先区分可见结构、已确认结构与未知区域；未知区域保持遮挡或选择不暴露它的视角。不能以“这类商品通常有”或场景需要为理由添加花柄、接口、底座、支撑件或配件；玫瑰花原图只展示花头时，不为插入花瓶而生成未确认柄部。必要时请求补充商品视图，或保留可信原商品层。布景道具可按任务设计，但不能与商品连成新结构或冒充随附物。

## 从实际参考选视觉机制

有用户参考或品质问题时，先读 [参考图谱](references/local-reference-atlas.md)，从 [文件索引](references/local-reference-index.json) 选与本次版位、受众、信息量相关的少量图，并实际打开。索引含55张用户参考与反例；图片不可访问时记录缺口，不声称看过。原商品图是身份参考，广告成品是构图/材质/字体参考，两者角色分开。方法研究按需见 [公开方法与图像来源](references/researched-layouts.md)。

写清 `参考ID/角色 → 看见的具体关系 → 为什么适用 → 进入哪条生成/编辑指令 → 不复制的内容`。当前用户明确：`不应该的图片`与`像电商首页的图片-文字量大元素多`目录的现有图片均为负面，其余目录为正面。按索引的 `polarity` 选择；正面用于品质/风格基准，负面只作诊断对照，不作为向往的生成风格输入。目录变动时先同步路径和角色，不按旧ID前缀分类。只提取机制，不搬品牌、价格、数字、标章或不相关道具，不把贴有品牌的参考自动当作已验证官方广告。

按目标选择或组合：商品材质、人与商品动作、生活场景、概念空间、图形与参数、完整促销信息组。商品或相关核心利益必须醒目；大标题、定制字形、强交易信息、色块及信息丰富的画面都可成立。不能默认极简、柔光、小字，也不能默认高饱和促销。文字、商品与环境要形成关系，避免商品被缩成独立侧栏配图。概念图不强制真实场景，可信悬浮不强制落地。

方向未定且品质重要时比较少量机制不同的小样；方向已选时直接发展或比较其内部变体，不机械重复生成。不能只换配色或用通用情绪词代替创意。遮住标题时检查商品/使用情境，遮住商品时检查文字是否有本次主题和品牌语气。

## 将文字也作为图像设计

先读 [文字与装饰生成](references/generative-typography.md) 选择路径。 文字品质反馈出现时，同时读 [实际文字研究](references/typography-reference-study.md) 并打开适用T1/A1原图；生成前明确主题、准确文案与关键构图关系，字形、局部强调、排法和装饰保留自主发展的空间，按[统一判断](references/typography-and-ornament.md)把握边界。“艺术字”或“全AI生成”不足以定义品质。保留好背景，局部精修字形和组合；不默认所有信息等粗、三枚等大圆形图标或同一种促销标题。**允许并优先考虑把标题、价格字形、卖点图标、标贴、按钮和有关装饰纳入整体生成**；文字必须准确，但不要求一律用系统字体后排。

先让模型整体协调商品、空间、光影、字体形态及交易信息。源图身份约束和必用文案逐项写入指令；输入参考按身份、构图、光影、文字角色标记。有正确文字和良好字形就保留，不为了可编辑性抹掉创意。

按事实风险和素材选择制作方法：

| 方法 | 适用判断 | 必做复查 |
|---|---|---|
| 整图生成/编辑 | 需要统一空间、文字和装饰，工具能处理本次文字 | 商品逐细节核对、所有文案逐字核对 |
| 原商品＋生成场景和创意文字 | 包装、纹样或Logo要求严格，已有适合的商品图 | 主体与文本空间、光影、边缘和支撑关系 |
| 生成标题/价格等独立视觉层＋合成 | 字形表现力重要，同时需要保留商品 | 文字透明边缘、风格一致、叠压不挡关键信息 |
| 局部确定性文字/Logo修正 | 错字、数字、条件仍无法可靠生成，或用户要求可编辑 | 修复字形和底纹与原设计一致，不退化成黑字矩形补丁 |

一张画面可以混合这些方法。内容、单一传播理由和交易信息的主次由任务决定，不把所有卖点和图标等权。必用条件不能删掉或缩到不可读；长条件应提前安排版位。可复用脚本只作为精确合成/修正工具，按需读 [排版工具约定](references/layout-contract.md)，不是成品默认模板。

标题、装饰、商品与空间共同发展。按[统一判断](references/typography-and-ornament.md)检查商品主导、自然阅读与整体协调；整行对比和局部强调都可成立，氛围与美感可独立成立。把审美要求写成结果目标，不预设固定字体、行组轻重或线型，也不在转译工具指令时另加保守样式限制；商品结构与必用信息仍须准确。

## 精修与验收

完整制作见 [执行与交付](references/production-playbook.md)，品质问题见 [视觉开发](references/art-direction.md)。保存候选/基线、实际指令与每次具体修正；局部问题沿用已有好画面，不反复全图重做。不得使用一团椭圆阴影代替所有支撑点，原图保真也不能抵消贴纸感。

打开实际导出，在原尺寸和接近投放/手机尺寸分别检查：

1. **身份与事实**：结构、图案、Logo/铭文正确；名称、标题、卖点、价格、币种、日期、CTA和限制条件逐字准确；尺寸、语言、数量符合任务。未修复的身份/事实错误只能标为概念或未完成，不能正式交付并声称通过。
2. **主题与信息**：能看出是什么、为何关注、如何行动；促销任务的价格/条件/CTA形成清楚的信息组，品牌任务不强加优惠与按钮。文字不能成为无设计的三行列表，图标不是随意配三枚。
3. **商品与空间**：拟真路线核对光向、颜色、反射、透视、边缘、景深、支撑点/手部接触与影子；概念悬浮检查空间和投影一致，图形路线检查形状、遮挡和网格。
4. **设计完成度**：标题字形与商品姿态/品牌对应；装饰可以只提供氛围、美感或节奏，以整体协调判断，不要求功能指向；商品仍醒目，各信息组不争抢第一注意点。增加留白或降低饱和度不是自动提升品质。

结合参考机制做具体差距判断。通过尺寸和文案检查不等于视觉达标；没有实测不宣称转化提升。用户评价“AI味重”时定位假反射、发光、过硬纹理、重复道具、字形问题，针对修改并保留有效张力。

## 交付

交付实际PNG/要求格式、真实尺寸、可重做材料及简短说明。整图生成保留输入、指令、编辑链和原文件即可，不要求伪造可编辑图层；合成路线附配置/源文件。附原尺寸与小尺寸复查、修正结果、事实来源和未解决项。参考研究是当前设计知识与技能规则更新，不是模型权重训练。
