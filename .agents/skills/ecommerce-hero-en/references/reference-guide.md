# Reference use

Purpose: select references and turn actual observations into production decisions. New work and major rebuilds view suitable originals through [quality benchmark](quality-benchmark.md); refinements retain selected references. An explicit prohibition on viewing references takes priority: work from the brief and design rules.

Image-derived elements and combinations appear in [visual forms](visual-form-reference.md). This document governs selection/use; the form document supplies design options.

## Library entry and roles

[local-reference-index.json](local-reference-index.json) records IDs, paths, dimensions, observations, roles and hashes. The 12 benchmarks reside in `references/images/2026-10-07补充/`. Their `path` and `relative_path` resolve against the skill root containing SKILL.md, with `path_base: skill_root`; moving/installing the package needs no path changes. Historical entries may use external absolute paths; check availability. Prefer bundled originals. Record unavailable comparisons rather than treating an indexed path as an available image.

Use `polarity`: `positive` supplies design/quality references; `negative` supplies diagnosis and repair comparison. Negative labels originate in the user's directories for rejected images and dense ecommerce-homepage imagery. Directory names and old ID prefixes do not define roles. Confirm roles and paths when moving/adding images.

Do not pass negative examples as aspirational style or quality input. Successful local relationships may be retained without changing their overall negative label. References supply composition, light, type and information relationships; [task evidence](production.md#establish-the-brief-and-product-evidence) establishes product/marketing facts. Viewing an image and passing it to a tool are different actions; record each accurately.

## From viewing to production

Open relevant originals, extract task-relevant relationships and decide how to adapt them. Record briefly: `ID/role → visible relationship → task adaptation → actual instruction/edit`. Borrow reading rhythm from type scale, highlight priorities from reflection, or viewpoint/action coherence from human crops. Rechoose fonts, line forms, palettes and props for the current concept.

An index-only read guides selection; visual judgment follows viewing the original. For an effective existing image, references can locate a local gap.

## Additional images and versions

Compare SHA-256 for identical files and reuse identical records. Similar names/products/compositions with different hashes remain independent versions; `related_reference_ids` records possible associations without replacing old IDs/classifications. Confirm visual duplication only after opening both originals. Entry counts are not counts of distinct designs.

New records retain dimensions, source, hash, visible relationships, applicable tasks and boundaries. Keep positive/negative compatibility. `reference_scope: user_quality_benchmark` identifies user-approved quality targets, benchmarked by relevant dimension; `mechanism_only` still permits local borrowing only. `classification_basis` and `quality_confirmed_on` retain approval evidence. Do not downgrade the 12 confirmed references to unapproved local examples.

New bundled files do not restore all historical originals. Prefer existing suitable paths; retain missing paths as history without claiming to view them. Viewing, generator input and asset reuse are distinct. Source titles do not establish click rates, lens parameters or platform compliance.
