# 实际文字参考研究（2026-10-03）

T1六张文字图与A1四张AI图均已逐张打开。观察是设计研究，不是模型训练、字体鉴定或转化证明。“宋体气质”只描述可见笔画粗细和衬线，不声称识别具体字体。

本文记录观察与历史复盘，不将案例形态作为强制模板。执行以[标题与装饰统一规则](typography-and-ornament.md)为准。

## 旧流程为何容易平庸

“巨大、漂亮、有设计感、整体AI生成”仍会落为等粗双行黑体、三枚等大圆形卖点、规则横线和粗黑129，因为没有定义字形差异、组合节奏和商品关系。过长的禁止清单又会删掉所有变化。保留事实和身份约束，同时正向写出希望看到的形态。

A1-03以普通字的轻重对照成立；A1-02用衬线气质和细字契合自然品牌；A1-01以压缩斜向字和黑红形成动势。它们是可选机制，不是品类永久指定字体。

## 装饰线条再观察（2026-10-03）

回应用户指出的“有意义不等于功能标注”，本轮再次逐张打开T1六张原图。不能将装饰品质检查执行成清空线条；氛围、美感与视觉节奏本身就是合理价值。

- T1-02：黄色弧线借球的弹跳轨迹表现轻快，与球场呼应；它不是参数引线，开放端点与断开的短笔触可以成立。
- T1-03：粗蓝回环跨越空白，与瓶组错位、标题斜向共成流动节奏；小箭头也带手绘感。不是每段曲线都需要明确商品指向。
- T1-04：黄色宽曲线形成活泼的背景节奏，与瓶子前后叠压；主要价值是色彩与动势，不是商品功能。
- T1-05：大括号既聚合品名，也通过弧度和尺度呼应手臂的柔和姿态；普通标点可以承担审美角色。
- T1-06：小回环箭头、太阳与云朵涂鸦增加亲切与轻松感，线条保持同一轻细语气；不要求复制符号或参考宣称。
- T1-01：此图没有同类自由装饰线；主要靠果实、气泡与留白建立鲜活感。图库的某些图有线，不意味着所有海报都必须加线。

用户当前玫瑰示例中的细红弧线可呼应标题笔画和浪漫/手作语气，让行间留白有流动感；不要求解释为花柄、气流或连接信息。用户粗红标记用于圈选，不是原海报线条。评价看曲率、起落、轻重、留白与整体语气；对突兀或残缺笔触局部整理，而非全删。实际指向线或产品功能图仍须清楚且有依据；商品原图未确认结构的约束不因此放宽。本轮更新规则，没有重新生图。

## 最近保温杯复盘与待验证方向

最近石台/帆布包图的满版背景与统一光线有保留价值；文字却“每行等粗黑体＋316/12同等粗数字＋三枚圆形图标＋粗129”，几乎每组语气相同。它在文案可读层面成立，不代表达到用户文字品质要求。

可沿用场景，借A1-02：标题用清楚笔画粗细差、收敛衬线和略窄字面，两行保持连贯但调整行距/字距；品名轻而紧凑，129延续标题气质；316/12与说明通过不同大小和重量形成组，不再每条同大圆形卡。全文、价格和日期保留。该方向尚未生成验证，不声称已经改善。

不要因为一张图问题而全局禁用黑体、斜字、图标、卡片或底栏；另有需求与用户选择时合理调整。

## 写入工具前与导出后的双检查

生成前简述：准确标题哪些词主次；字形粗细/宽窄/笔端；行组节奏；商品关系；价格、卖点、日期和CTA层级。挑一两个适用变化，不叠六种效果。

导出后对照意图：实际是否仍等粗等大、同一行距；关键词与商品是否建立关系，细字是否可读，数字单位是否齐全。意图未落实就是文字问题，保留好场景局部修字；不是重新生一张背景。本轮只更新技能，尚无新增海报或盲测。
