# 作业要求摘要

依据课程提供的 `Task.pdf`。正式要求请以原文件及教师后续通知为准。

## 选题和目标

- 选题：电商商品营销主视觉设计。
- 传播目标：使消费者快速理解商品核心价值，形成点击或购买意愿。
- 典型输入可包括商品图、商品参数、卖点、价格、活动规则和画布规格。

## Skill 应覆盖的流程

需求分析 → 资料组织 → 方案构思 → 生成与制作 → 评价与迭代。

文档应清楚到另一位同学不用口头解释，也能使用 Skill 完成同类任务。课程示例仅是参考，不代表最低或最高输入要求。

## 最终交付

1. 中文版与英文版的完整 Skill 文件。
2. 使用课程统一模板撰写的 LaTeX 测试报告。

## 待课程发布

- 统一设计测试任务及其具体输入。
- LaTeX 测试报告模板。
- 如有补充：截止时间、提交方式、评分细则。

在这些信息发布前，可自拟商品任务用于发现和修订 Skill 的问题，但不要将自拟任务当成正式测试。
