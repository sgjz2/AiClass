# 电商主视觉 Skill v4：文字设计与整体生成

版本日期：2026-10-03。

本次发布包含 `ecommerce-hero-zh`、`ecommerce-hero-en` 和 `ecommerce-art-director-demo` 三个入口，以及执行、参考研究和按需排版脚本。下载三个入口与支持文件的压缩包：[v4 源码包](../deliverables/ecommerce-hero-skills-v4-20261003-source.zip)。

## 本轮变化

- 将标题、价格、卖点图标、按钮和装饰纳入整体图像生成；系统字体排版作为精确修正或可编辑交付的可选路径。
- 从具体参考拆解字形粗细、宽窄、笔端、行组节奏及商品关系，避免只写“高级艺术字”、等粗标题或默认三个圆形图标。
- 保留连续背景、非必要不加底部全宽文字带、商品为主体，以及人物裁切须符合机位与动作的规则。
- 同步 53 张本地参考的索引与观察记录，其中 43 张正面、10 张负面；新增 10 张文字与 AI 成片研究。
- 要求生成后分别核对商品身份、逐字文案、字形效果、空间光影及手机尺寸可读性。

## 如何使用

在 Codex 中打开本仓库，选择对应入口并提供商品图、需求与参考。其他环境可将一个 skill 的完整目录复制至自己的 skills 目录。脚本只用于按需合成和修正，不能代替真实生图工具。

参考索引中的 `path` 是作者本机的图片位置，原始参考图片没有上传到本仓库或源码包。使用自己的图库时，将三个入口的 `references/local-reference-index.json` 路径指向可访问文件，并同步相应图谱及正负角色；没有原图时，研究文字只能作为方法说明，不能声称实际查看或输入了图片。索引中的哈希对应原参考，用于辨认素材。上传源码不授予第三方参考图的再分发权。

## 试跑证据与限制

相机、鞋、吹风机和玫瑰花案例均保存了实际生成指令、商品输入、原图、1200×1500 输出及 360×450 预览。使用内置生图工具整体生成，部分案例实际传入文字参考；效果不是只依赖 skill 文本而得出。成片和案例原素材保留在本地 `Example/对应案例/v4文字优化测试-20261003/`，不包含在本次源码上传中。

用户在玫瑰花案例之后认可此版的视觉表现。这个反馈不是受控对比或转化率证据。整体生成仍可能改变商品细部结构、铭文或图案，试跑输出是视觉方向测试稿，不能据此宣称全部满足严格商品保真或可正式投放。

官方 skill 校验器因本地缺少 PyYAML 未执行成功。已做入口元信息、本地文档链接、索引数量及一致性、原参考路径与哈希、压缩包回读检查；这些检查不等同于视觉质量验收。
