# 协作与试跑计划

## 工作顺序

1. **需求与资料**：核对课程要求，定义 Skill 必需输入和缺失信息的处理方式。
2. **Skill 初稿**：共同审阅中英文流程，确认两版意思一致且能由其他同学独立执行。
3. **内部试跑**：选一种商品，准备有来源的图片、卖点、价格和活动信息；由未参与撰写的组员按 Skill 完成任务。
4. **评价与修订**：记录输入、提示、设计结果、问题与修改前后差异；优先修复真实试跑中出现的含糊步骤。
5. **正式测试**：课程发布统一任务和 LaTeX 模板后，按指定条件测试并完成报告。

## 提交修改

每项工作建独立分支，例如 `skill/input-contract`、`test/first-run`。PR 写明：改了什么、为什么改、如何验证、是否需要同步另一语言版本。涉及主视觉的 PR 附低分辨率预览和素材来源说明。至少请另一位组员阅读后再合并。

## 试跑记录最少包含

商品与传播目标、输入资料及来源、所用 Skill 版本、执行步骤与关键决策、产物、评价结果、发现的问题、修订建议。请勿把账号凭证、未授权的客户资料或无许可素材上传仓库。
